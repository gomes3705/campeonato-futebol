Campeonato de Futebol

Sistema em Java, via console, para gerenciar um campeonato de futebol. Dá pra cadastrar times, registrar partidas e ver a tabela de classificação atualizada automaticamente.

Feito para a matéria de Projeto de Programação, usando POO.

Como funciona

O sistema tem 3 classes:

Time: nome, pontos, vitórias, empates, derrotas e gols do time.

Partida: representa um jogo entre dois times, com o placar.

Main: menu no console pra cadastrar times, registrar partidas e mostrar a classificação.

Regras: vitória vale 3 pontos, empate vale 1, derrota não soma nada. Em caso de empate na pontuação, desempata pelo saldo de gols.

Como rodar
javac Time.java Partida.java Main.java
java Main
